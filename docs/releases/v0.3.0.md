## GTA SA Open Downgrader v0.3.0

The first stable release of the native Go/Fyne rewrite, replacing the Python-based v0.2.x app. Supports NewSteam R2 Global and German installations, with validated patches targeting v1.0 US (Hoodlum).

### What's new

- Guided first-run setup, compact mod rows, inline details and settings, and clearer downgrade reviews.
- Redesigned Tools and Recovery pages, a shared progress footer, and improved menu/dialog responsiveness.
- Windowed Mode, Open Limit Adjuster, LOD Vegetation, and curated font/interface packages with dependency handling and verified archive imports.
- A single browser-assisted ShareMods queue that detects completed downloads, reuses verified archives, and preserves the original browser downloads. ShareMods confirmation remains manual.
- Steam/Proton integration for multiplayer and the optional Steam launcher v4, including reliable singleplayer exit tracking and recovery after interrupted compatibility changes.
- Detailed operation logs with timings, hashes, download diagnostics, backup/rollback decisions, and local rotation. The log reader adds wrapped entries, compact timestamps, filters, search, and optional 30-day sharing for GitHub issues.
- Linux/Wayland desktop icon registration, refreshed screenshots, and smaller Actions caches that retain module downloads only.

### Downloads

Windows x64 executables and Linux x64 AppImages are available in online and offline variants. Offline builds include validated Global/German patch assets; mods and multiplayer still require internet access. Linux releases target Ubuntu 22.04 / glibc 2.35 or newer.

Steam launcher v4 has its own [stable release](https://github.com/xxanqw/gtasa-open-downgrader/releases/tag/launcher-4). Install or update it from **Multiplayer → Steam launcher → Check updates**.

### Before changing game files

Close GTA, keep backups, and review the target folder and file changes. Cancellation stops further work without undoing completed changes. Recovery restores downgrade originals without uninstalling mods.

Open Limit Adjuster is shared by LOD Vegetation and Project 2DFX; tracked older copies are migrated with backups and settings preserved. LOD Vegetation can conflict with map packs and is included in Proper Fixes. Keep Project 2DFX's `LoadAllBinaryIPLs` at `0`; SA-MP needs the author's manual IDE setup. Linux multiplayer remains experimental.

The legacy Python source is preserved on the `v0.2.3` branch. New development continues on `main`.
