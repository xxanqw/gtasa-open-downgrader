## v0.3.0

v0.3.0 is a complete rewrite and expansion of the Python-based v0.2.3 application. It brings a native interface, multiplayer management, a standalone Steam launcher, a larger mod catalog, configuration editing, and shareable diagnostics.

### Native Go application

- Rebuilt the application in Go with Fyne, replacing the Python/Qt application and its PyInstaller packaging.
- Added a new workspace with Game, Mods, Multiplayer, Tools, and Recovery views, native file pickers, and consistent dialogs.
- Introduced guided setup for choosing the game folder, preparing patches, verifying files, and reviewing the downgrade.
- Added one shared progress footer with complete action text, cancellation feedback, and persistent interruption warnings.

### Expanded mod management

- Added Windowed Mode, Open Limit Adjuster, LOD Vegetation, Extended Fonts/ELL, and optional HD radar, HUD, and weapon-icon packages alongside the existing fixes.
- Added dependency-aware selection, selective updates, individual removals with backups, compact rows, and expandable installation/version details.
- Added a built-in configuration editor with syntax highlighting, find/replace, undo/redo, and backed-up saves for supported mod settings.
- Added guarded installation and update transactions, preservation of existing configuration, and recovery of tracked legacy installations.

### Browser-assisted ShareMods downloads

- Added a download queue for selected packages and their required helpers.
- The app detects completed browser downloads, validates matching archives, reuses shared packages and verified cache entries, and continues installation when everything is ready.
- Existing archives can be selected or imported without downloading them again. ShareMods download confirmation still happens manually in the browser.

### Multiplayer and Steam launcher

- Added installation and management for SA-MP, open.mp, and MTA, including detection of the game's Steam Proton environment on Linux.
- Added an open.mp server browser under Proton and client-specific compatibility handling that restores temporary changes after GTA exits.
- Added the optional Steam launcher: choose singleplayer or a multiplayer client when launching through Steam, with an optional remembered mode and a cancellable countdown.
- The included launcher version is **4**, with reliable singleplayer process-exit tracking and recovery after interrupted multiplayer sessions. Its [standalone stable release](https://github.com/xxanqw/gtasa-open-downgrader/releases/tag/launcher-4) updates independently of the downgrader.

### Diagnostics and issue reporting

- Added detailed operation logs covering timings, file hashes, downloads, backups, rollback decisions, and underlying errors, with bounded local rotation.
- Added a dedicated log reader with wrapped entries, compact timestamps, highlighting, filters, search, copy, and export.
- Added an optional issue-reporting flow that uploads a log only after confirmation, provides a searchable 30-day sharing link, and prepares a GitHub issue containing that link.

### Compatibility and downloads

Support remains **NewSteam R2 Global and German → v1.0 US (Hoodlum)**. Windows x64 executables and Linux x64 AppImages remain available in online and offline variants. Offline builds include the patch assets; mods, multiplayer clients, and updates need internet access. Linux builds target Ubuntu 22.04 / glibc 2.35 or newer and include desktop/Wayland icon integration.

Linux multiplayer support is experimental. Close GTA before changing files and keep your backups; cancelling stops further work without undoing completed changes.

Development now continues on `main`. The final Python implementation is preserved on the [`v0.2.3` branch](https://github.com/xxanqw/gtasa-open-downgrader/tree/v0.2.3).
