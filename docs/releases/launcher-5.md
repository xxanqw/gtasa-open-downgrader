## Changes since launcher v4

- Detect and launch the portable open.mp installation created by downgrader v0.3.1 under Proton.
- Use the managed open.mp client files for the selected SA-MP version when joining a server.
- Align hyperlink hover underlines with their text.

## Install or update

Close GTA and the launcher, then use **Multiplayer → Steam launcher → Check updates** in the downgrader.
