## v0.3.1

- The Linux downgrader now installs and repairs open.mp from its official portable package, avoiding the WebView2 installer failure under Proton ([#6](https://github.com/xxanqw/gtasa-open-downgrader/issues/6)).
- MTA Manager has a version picker with installation details and actions for each version. MTA 1.6 uses the official stable download, and MTA 1.7 uses the latest development client listed by MTA. The downgrader verifies the publisher signature and signed SHA-256 before running either installer.
- Hyperlink underlines now sit directly below the text in the downgrader and Steam launcher.

### Steam launcher

Launcher version 5 supports the new portable open.mp installation under Proton. To update an existing launcher installation, use **Multiplayer → Steam launcher → Check updates**. [Steam launcher v5 release notes](https://github.com/xxanqw/gtasa-open-downgrader/releases/tag/launcher-5)
