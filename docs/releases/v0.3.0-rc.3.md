## Changes since RC.2

- Reworked first-run setup: identify the game folder, install or import patches, then verify files before reviewing the downgrade.
- Compact Mods list with inline details, versions, settings, ShareMods info tooltips, and selection actions beside Update installed.
- Added Windowed Mode beside Widescreen Fixes, Open Limit Adjuster, and LOD Vegetation v1.2. Required dependencies are selected automatically.
- ShareMods downloads now use one queue, detect completed archives in any order, reuse shared downloads and verified cache entries, and accept existing archives. ShareMods confirmation still happens manually in the browser.
- Structured downgrade and installation reviews replace long text-only confirmations. Errors include recovery guidance and copyable diagnostics.
- One shared progress bar with full action text for downloads, installation, downgrading, and restoration.
- Reduced stalls when opening menus and dialogs; improved compact layouts and Linux/Wayland desktop icon registration.
- Added Tools → Open downgrader folder and refreshed README screenshots.
- Bundled Steam launcher updated to v4, including reliable Singleplayer exit tracking and recovery of identical active/disabled Mod Loader copies.

Open Limit Adjuster is shared by LOD Vegetation and Project 2DFX. Older tracked Project 2DFX copies are migrated with settings and backups preserved. Unmanaged duplicates require reconciliation.

LOD Vegetation replaces map IPL files and can conflict with map packs; it is already included in Proper Fixes. Keep Project 2DFX's LoadAllBinaryIPLs at 0. SA-MP needs the manual IDE setup described by the mod author. Linux multiplayer remains experimental.

## Downloads

Choose the Windows executable or Linux AppImage. Online builds download patches when needed; offline builds include the validated Global/German patch assets. Mod downloads require internet access.

This is a release candidate. It does not replace the latest stable downgrader release or enter its automatic update channel. Close GTA before changing files, and retain backups until verification finishes.
